## 2. 평가 세트

| 세트 | 문항 | 출처 | 용도 |
|---|---|---|---|

| v2 한국어 | 96 → 95 | 영어판과 다른 맥락 없는 세션이 작성, 레포 밖 | 판정 원칙 적용 |

- v2는 문서마다 6문항(상품명 없음 4·있음 2)이고 한국어 문항이 `pairId`로 영어 문항과 짝을 이룬다.
  짝끼리 goldDocument·goldQuote·상품명 유무가 모두 같다(96쌍 확인).
- 제외 1쌍(측정 전 결정): v2k-043과 짝 v2-043. v2k-043이 고정 세트 s14(선택에 쓴 문항)와 거의 같은 질문이었다
  (공백 제거 뒤 글자 2-gram Jaccard 0.719). 그 결과 v2는 190문항(95쌍).
- 모든 세트에서 invalid 문항은 0개다(goldQuote가 모두 해당 문서 추출 텍스트에 있었다).

## 3. 미리 정한 것

### 비교안과 고정값

| 방식 | 내용 |
|---|---|
| ① | chunk_blocks 기본 설정 + BGE-M3 dense 코사인 |
| ② | ①과 같은 청크, 임베딩 입력에만 `[상품명] {문서 이름} / [섹션] {섹션 제목}\n`을 붙임. 섹션 제목은 chunk_blocks의 `section_title`만 쓰고 없으면 상품명만(섹션 제목 있는 청크 129/145). 질의는 그대로 |
| ③ | ① dense(prefix 없음)와 같은 청크 본문 BM25(k1=1.5, b=0.75)를 각 상위 20개씩 RRF(k=60)로 합친 뒤 상위 5. BM25 토큰: 공백으로 나눈 토큰(영문 소문자) + 공백을 뺀 한글 글자 2-gram |

- 근거 적중은 언제나 prefix 없는 청크 본문으로 판정한다. 임베딩은 revision + 청크 본문 해시 + prefix 방식을 키로 캐시했다.

### 지표

모두 상위 5 청크 기준. 문서 순위는 같은 문서의 청크를 첫 순위만 남긴 문서 목록의 순위다.
Recall@5(주 지표), 근거 적중@5(정답 문서의 상위 청크에 goldQuote가 공백·줄바꿈 무시하고 들어 있음), MRR@5, Recall@1.

### 선택 규칙(v1 고정 세트에 적용)

순서: 문서 Recall@5 → 근거 적중@5 → MRR@5 → 지연 중앙값 → 단순함(① > ② > ③).
각 단계에서 최고값과의 차이가 1문항 이하(Recall·근거 적중 1/30, MRR 0.034, 지연 20%)인 후보를 동점으로 남긴다.

### v2 판정 원칙

선택은 ③ 그대로. v2-ko에서 ③의 Recall@5 적중이 ①보다 2문항 이상 적을 때만 재검토한다.
v2-en은 선택에 쓰지 않고 실사용 언어 조건으로 따로 보고한다.

### 실패 분류(v1 고정 세트 ① 실패 문항)

A 추출 / B 공통 문구 / C 질문 모호 / D 표현 차이 / E 약관 혼동 / 불명(확신 없음). C는 평가 세트 문제일 수 있어 따로 보고한다.

### invalid 규칙

goldDocument가 말뭉치 문서에 매핑되지 않거나 goldQuote가 그 문서 추출 텍스트에 없으면(공백·줄바꿈 정규화 후)
문항을 고치지 않고 invalid로 표시해 집계에서 뺀다.

### 4-2. McNemar와 부트스트랩 95% 구간

부트스트랩: 문항 복원 추출 10,000회, 시드 20261116, 95% 백분위 구간(같은 추출을 모든 방식에 사용).
칸은 `적중/n 평균 [하한, 상한]`.

## 5. 결론

- **선택은 ③ 유지.** v2-ko Recall@5 적중 ③ 81 vs ① 78로 판정 원칙(③이 2문항 이상 낮으면 재검토)에 해당하지 않는다.
  다만 이 차이도 유의하지 않다(McNemar b=5, c=8, p=0.581).
- v1 고정 세트에서 보인 Recall@5 차이(27→29)는 작은 표본에서 크게 보였던 것으로, v2에서는 줄었다
  (v2-ko 0.821 → 0.853, v2 전체에서는 ③이 오히려 0.705로 ① 0.726보다 낮음, 모두 유의하지 않음).
- 영어 질문에서는 모든 방식이 떨어지고(Recall@5 0.56~0.64), ③의 1위 정답이 7/95로 ①(30/95)보다 유의하게 낮다
  (b=23, c=0). 한·영 짝으로 보면 같은 내용이라도 한국어 질문 쪽이 상위 5 안에 드는 경우가 훨씬 많다.
  **질문 언어가 검색 방식보다 큰 변수다.**

## 6. 운영 결정 (2026-11-16 태건 확정)

- 챗봇이 검색 도구를 부를 때 LLM이 검색어를 한국어로 작성한다. 도구 설명에 이 규칙과 상품 16개의 한국어 이름을 넣는다.
- 그 검색어로 ③을 쓴다. 검색어에 한글이 없으면 ①로 대체한다.
- 연결한 뒤 챗봇이 만든 검색어로 v2 영어 질문을 다시 측정할 예정이다.

## 7. 공개 목록

- 측정 전 코드 수정(v2): v2 형식 로더(최상위 배열, hasProductName → namesProduct, page 없음, language·pairId 유지),
  goldDocument 끝의 `.pdf`를 떼고 매핑(v1 영향 없음), 문항 제외 옵션(`--exclude-ids`, 이유 기록),
  언어별·한국어 겹침별 집계와 한·영 짝 비교, 정확 McNemar·부트스트랩 통계.
- 미리 정하지 않은 BM25 구현 세부: idf = ln(1 + (N − df + 0.5) / (df + 0.5)), 질의 토큰 중복 제거,
  한글 2-gram 토큰에 `2:` 접두, BM25 점수 0인 청크는 상위 20에서 제외, 동점은 청크 순서(dense·BM25·RRF 모두),
  방식마다 워밍업 질의 '정기예금 가입 조건' 1회 뒤 지연 측정.
- 실패 분류 라벨은 Claude Code가 붙였다. 불명 4(s02, s06, s11, s22).
- 질문이 goldQuote를 베낀 문항 1개: v2k-031(공백 제외 연속 11자).
- 정답 문서가 하나로 정해지지 않을 수 있어 보이는 표본 3쌍(모두 상품명 없음): v2-027/v2k-027, v2-071/v2k-071, v2-023/v2k-023.
- 짧은 goldQuote(예: '연 3.15%', '월 300만원 이하')는 근거 적중 판정이 느슨할 수 있다(정답 문서 안에서만 세지만 문서 안 위치는 구분하지 못함).
- 지연은 CPU 측정 잡음이 커서 비교하지 않았다(같은 dense 계산인 ①·②의 차이, 더 많은 계산을 하는 ③이 더 빠르게 나온 경우가 있었다).
- Recall@1·근거 적중은 보조 지표다. 선택의 1순위 기준은 Recall@5다.
- ② prefix가 v2 전체 근거 적중에서 가장 높았지만(0.595, ②vs③ p=0.003) 1순위 기준이 아니라 선택하지 않았다.
- v2 영어판과 한국어판은 서로 다른 맥락 없는 세션이 작성했다.
