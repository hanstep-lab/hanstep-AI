## 4. 판정 규칙과 지표 (측정 전에 정함)

판정은 ok / 위반 / 판정 불가(조건표 값 null) 셋이다.

| 조건 | 위반 | 판정 불가 |
|---|---|---|
| 추천 대상 | recommendable=false 상품, 조건표에 없는 문서(약관) | – |
| 상품 종류 | 요청과 다른 예금/적금 | – |
| 외국인 | foreignerEligible=false일 때만 | null |
| 비자 | visaTypes에 프로필 비자 없음 | null |
| 나이 | ageMin·ageMax 중 있는 값 밖 | 둘 다 null |
| 체류 기간 | 가장 짧은 계약기간(termOptions 최소, 없으면 termMonthsMin) > 남은 체류 개월 | 기간 null |
| 월 여유자금 | 적금의 월 최소액 > 월 여유자금. 예금은 비교하지 않음(월 흐름과 목돈은 단위가 다름) | 적금 월 최소액 null |
| 요청 기간 | 가장 짧은 계약기간 > 요청 상한 | 기간 null |
| 요청 월 납입액 | 납입 범위 밖(noLimit 상한은 통과). 요청액 > 월 여유자금이면 모든 상품 위반 | 월 범위 null |
| 적립 방식 | savingType이 요청과 다름 | null |

- gold 후보 = 위반 없음 + 요청 조건(요청 기간·월 납입액·적립 방식)에 판정 불가 없음 + goldRequires 충족.
  프로필 조건(나이·비자)의 판정 불가는 gold에서 빼지 않는다.
- Recall@5 = |상위 5 ∩ gold| / min(|gold|, 5), gold가 있는 26문항 평균.
- gold 0개 문항 기권율 = gold 0개 문항 중 아무것도 추천하지 않은 비율.

## 6. 해석

- 검색만으로는 프로필을 볼 수 없어서 체류 기간 위반(40)이 가장 많다. 남은 체류가 짧은 P1·P2·P4에 몰려 있고,
  P2(5개월)는 R1·R4에서 gold를 하나도 맞히지 못했다.
- 요청 조건 중 '3개월 이하'(R2)는 검색이 기간을 구분하지 못해 6·12개월 상품 3개를 함께 올린다.
- 추천 대상이 아닌 쏠편한 선물하는 적금이 적금 요청 세 개(R1·R4·R6)에 모두 들어간다.
- gold 0개 문항 4개에서 기준선은 언제나 5개를 추천한다(기권 0/4).
- R3·R5의 Recall@5 1.000은 gold가 작고(1~4개) 상품 종류가 검색어와 잘 맞아서다. 예금 조건(최소 가입액)은
  이번 판정에서 쓰지 않았다.

## 7. 한계

- 한 달부터 적금은 한도가 주·일 단위라 월 납입 요청(R4)에서 판정 불가로 gold에서 제외.
- foreignerEligible의 inferred(12개)는 해석이다. 위반은 false일 때만 세므로 외국인 조건 위반은 구조상 0이다.
- visaTypes가 모두 null이라 비자 조건은 전부 판정 불가(150)다.
- 예금은 월 여유자금과 비교하지 않는다. 프로필에 목돈 값이 없어 예금 최소 가입액 조건을 적용하지 않았다.
- 같은 요청이면 프로필이 달라도 추천이 같다(기준선은 검색어만 씀). 프로필별 차이는 gold와 판정에서만 생긴다.
- 30문항, 결정적 1회. 통계 검정은 하지 않았다.

## 8. 공개 목록

- 측정 뒤 평가기 수정: 없음.
- 측정 전 결정(사용자 확인): 조건표 수정(foreignerEligible 3단계, termOptions, recommendable,
  S드림 비대면 최소액), 프로필 수정(P2 체류 6→5개월, P5를 P3 체류 + 만 40세로), R2 6개월→3개월,
  예금의 여유자금 비교 제거, P4-R4 gold 비움과 expectedReason.
- 조건표 값과 gold 후보 계산은 Claude Code가 하고 사용자가 확인했다.
- 상품 순위의 동점은 먼저 나온 청크 순서로 정한다(RRF 결과가 이미 점수 내림차순).
- Recall@5 분모는 min(|gold|, 5)(gold가 5개를 넘는 문항도 1.0이 가능하도록).
